# Agent notes

This repository is a local retrieval experiment. The product type is `SourceDocument`. Benchmark annotations stay in `multilingual_local_rag.benchmark`.

Do not implement retrieval in a change that only claims to add contracts. Do not copy host paths into the tree. Do not call an unqualified `python` on a developer machine; use the repository virtualenv.

Public docs and comments stay in English. The public-v1 fixture keeps Russian and English source text.
